# Agent Spec: F-35 Fleet Sustainment Agent (`f35-sustainment-agent`)

> **Architectural Guardrail (Mandatory):** Agent Gateway is **NOT** used. The solution runs directly on **Agent Runtime** in `europe-west1` and uses a dedicated Google Cloud Service Account (`f35-sustainment-runtime-sa@antig-dave.iam.gserviceaccount.com`) to authenticate tools, BigQuery, and Discovery Engine APIs.

## Overview
The **F-35 Fleet Sustainment Agent (`f35-sustainment-agent`)** is a multi-agent ADK 2.0 sustainment system designed for Google Cloud's **Agent Platform** (**Gemini Enterprise Search and Conversation**, **Agent Runtime**, and **Agent Registry**). Agent Gateway is strictly omitted; tool execution and data access are authenticated directly via Agent Runtime and a dedicated Service Account.

All GCP services reside strictly in **EU** (`eu` multi-region for Gemini Enterprise & Discovery Engine, `EU` multi-region for BigQuery) and all compute/runtime infrastructure is deployed to **`europe-west1` (Belgium)** in GCP project `antig-dave` (`284046449012`).

It compresses fifth-generation F-35 Lightning II maintenance, supply, and technical diagnostic workflows from hours to seconds by coordinating three specialized domain sub-agents:
0. **UC0 / 0.1 / 0.5 Sub-Agent — `f35_maintenance_data_agent` (`@F35-Maintenance-Data`)**: Translates natural-language maintenance logbook, PHM/BIT fault event, and work-center tooling/SQEP queries into read-only BigQuery Standard SQL (`SELECT` and multi-table `JOIN`s) against `maintenance_work_orders`, `phm_bit_fault_events`, and `work_center_tooling_and_sqep` in `ukd_f35_sustainment_demo` (`location="EU"`, 100 records per table across all 6 warehouse tables = 600 records), guarded by the 3-Layer Operational Semantic SQL Canonicalizer (`ISS-013`). Returns an Excel / Google Sheets-like Spreadsheet Card with Column Letters (`A`..`Z`), Status/Severity/Calibration Badges, Formula Summary Footer Rows (`=COUNTA()`, `=SUM()`, `=AVERAGE()`), and automatic `.CSV` export.
1. **UC1 Sub-Agent — `f35_analytics_agent` (`@F35-Sustainment-Analytics`)**: Queries partition-pruned BigQuery tables in `EU` (`airframe_component_telemetry`, `global_depot_inventory`, `squadron_sortie_schedule` in `ukd_f35_sustainment_demo`), generates operational Markdown tables, triggers automated depot replenishment alerts, recommends tail-swap sortie reallocations, and renders on-demand 16:9 presentation slide graphics (`chart_painter.py`) + inline Vega-Lite v5 charts.
2. **UC2 Sub-Agent — `f35_jtd_search_agent` (`@F35-JTD-Search`)**: Performs single-pass dense semantic retrieval (`pageSize=15`, `snippetSpec` only) across S1000D JTD manuals (`ukd-f35-jtd-ietm-ds`) and 5-year multi-service narrative logs (`ukd-f35-narrative-logs-ds`) hosted in `eu` (`eu-discoveryengine.googleapis.com`), normalizing UK/US maintenance terminology (`RAF`, `RN`, `USAF`, `USMC`) across `DOC-01`, `DOC-02`, `DOC-03`, and `DOC-09` with verbatim `[Title](URI)` citations.

## Language
`python` (Python 3.11+, `google-adk >= 2.0.0`, `google-genai`).

## Architecture & Sub-Agents
- **Deployment & Data Residency**:
  - **GCP Project**: `antig-dave` (`284046449012`)
  - **Runtime & Compute Region**: `europe-west1` (Belgium) for Agent Runtime, Agent Registry, Cloud Build, and Artifact Registry.
  - **Data & Search Residency**: `EU` multi-region for BigQuery (`ukd_f35_sustainment_demo` — 6 tables × 100 rows = 600 rows), `europe-west1` for GCS buckets, and `eu` multi-region (`locations/eu`) for Gemini Enterprise and Discovery Engine datastores.
- **Runtime Multi-Agent Topology**:
  - **`root_agent` (`f35_sustainment_coordinator`)**: Root `LlmAgent` wrapped in `App(name="app", root_agent=root_agent, resumability_config=ResumabilityConfig(is_resumable=True), context_cache_config=ContextCacheConfig(min_tokens=2048, ttl_seconds=1800, cache_intervals=10))`. Routes incoming prompts across three strictly separated specialist sub-agents (`sub_agents=[f35_maintenance_data_agent, f35_analytics_agent, f35_jtd_search_agent]`):
    - **`f35_maintenance_data_agent`**: Dedicated to UC0 / UC0.1 / UC0.5 conversational Text-to-SQL and multi-table `JOIN`s over `maintenance_work_orders`, `phm_bit_fault_events`, and `work_center_tooling_and_sqep`, Excel / Google Sheets Card rendering, and automatic GCS `.csv` export (`app/sub_agents/uc0_maintenance_agent.py`).
    - **`f35_analytics_agent`**: Dedicated to UC1 structured BigQuery telemetry, inventory, sortie scheduling, on-the-fly 16:9 presentation chart rendering, and Vega-Lite chart generation (`app/sub_agents/uc1_analytics_agent.py`).
    - **`f35_jtd_search_agent`**: Dedicated to UC2 unstructured Discovery Engine (`eu`) JTD/FRACAS semantic retrieval and cross-service jargon translation (`app/sub_agents/uc2_search_agent.py`).

## Tools Required (Human-Friendly & Readable Tool Definitions)

0. **`execute_maintenance_sql`** (Display: *Execute Maintenance Work Order SQL & Render Spreadsheet Card* | `f35_maintenance_data_agent`):
   - Canonicalizes incoming SQL via `canonicalize_maintenance_sql`, validates and executes a read-only BigQuery Standard SQL `SELECT` / `JOIN` query against `antig-dave.ukd_f35_sustainment_demo` (`maintenance_work_orders`, `phm_bit_fault_events`, `work_center_tooling_and_sqep` in `location="EU"`), uploads the result set as a `.csv` file to `gs://antig-dave-f35-staging-europe-west1/exports/`, and returns a pre-formatted Excel / Google Sheets-like Spreadsheet Card.
1. **`check_actuator_fatigue_and_depot_inventory`** (Display: *Check Actuator Fatigue & Depot Inventory* | `f35_analytics_agent`):
   - Queries BigQuery (`EU`) tables (`airframe_component_telemetry`, `global_depot_inventory`, `squadron_sortie_schedule`) and returns structured rows plus a pre-formatted Markdown summary table.
2. **`recommend_tail_swap_and_replenishment`** (Display: *Recommend Tail Swap & Depot Replenishment* | `f35_analytics_agent`):
   - Generates an automated depot replenishment alert for actuator `NSN: 1680-01-619-4821` (18-hr shipping ETA) and reallocates morning sortie `SRT-MAR-20261103-01` (`Flt Lt Henderson`) from `ZM151` to serviceable spare `ZM154`.
3. **`render_sustainment_chart`** (Display: *Render Sustainment Chart & Presentation Slides* | `f35_analytics_agent`):
   - Dynamically renders Full HD 16:9 widescreen PNG charts on the fly in memory (~300–450 ms) using headless Matplotlib (`Agg` backend at 160 DPI), uploads to `gs://antig-dave-f35-staging-europe-west1/charts/<chart_name>.png`, and returns an authenticated HTTPS browser download link alongside Vega-Lite v5 JSON specifications.
4. **`search_technical_manuals_and_repair_logs`** (Display: *Search Technical Manuals & Maintenance Logs* | `f35_jtd_search_agent`):
   - Dense semantic retrieval across S1000D JTD manuals (`ukd-f35-jtd-ietm-ds`) and 5-year multi-service maintenance narratives (`ukd-f35-narrative-logs-ds`) hosted in `eu` (`pageSize=15`, `snippetSpec` only, HTML stripped, UK/US dialect normalization) with verbatim `[Document Title](URI)` citations (`DOC-01`, `DOC-02`, `DOC-03`, `DOC-09`).
